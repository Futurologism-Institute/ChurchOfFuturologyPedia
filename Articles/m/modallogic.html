Modal Logic

Extension of classical propositional (or predicate) logic with operators □ (necessity) and ◇ (possibility).

Syntax
If φ is a formula then □φ and ◇φ are formulas.
◇φ ≜ ¬□¬φ
Kripke Semantics
A frame is a pair (W,R) where W is a set of worlds and R ⊆ W×W an accessibility relation.
A model is (W,R,V) with valuation V.
M,w ⊨ □φ iff ∀v (wRv → M,v ⊨ φ)

Normal Systems

  • K: □(φ→ψ) → (□φ → □ψ) + Necessitation
  • T: K + □φ → φ  (reflexive)
  • S4: T + □φ → □□φ  (reflexive + transitive)
  • S5: S4 + ◇φ → □◇φ  (equivalence relation)
