Model Theory

A structure (or model) for a first-order language ℒ is a pair 𝔐 = (M, I) where M is a non-empty domain and I interprets the constant, function and relation symbols of ℒ.
Satisfaction
𝔐 ⊨ φ[ā] is defined inductively (Tarski’s definition of truth).
Elementary Equivalence
𝔐 ≡ 𝔑 iff 𝔐 and 𝔑 satisfy exactly the same first-order sentences.
Compactness Theorem
A set of first-order sentences has a model iff every finite subset has a model.
Löwenheim–Skolem
If a countable theory has an infinite model, then it has models of every infinite cardinality.
Completeness (Gödel)
T ⊨ φ ⇔ T ⊢ φ
