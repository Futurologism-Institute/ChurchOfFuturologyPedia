Turing Machines

A (deterministic single-tape) Turing machine is a 7-tuple
M = (Q, Σ, Γ, δ, q₀, q_accept, q_reject)
where:
  • Q finite set of states
  • Σ finite input alphabet (blank ∉ Σ)
  • Γ tape alphabet, Σ ⊆ Γ, blank □ ∈ Γ
  • δ : Q × Γ → Q × Γ × {L,R} transition function
  • q₀ ∈ Q start state
  • q_accept, q_reject ∈ Q distinct halting states

Configuration

A configuration is a triple (q, u, v) where q ∈ Q, uv is the tape content (u left of head, v right including current cell).

Computation

One step: apply δ to current state and scanned symbol, update state, write symbol, move head.

M accepts w iff there is a finite sequence of configurations from the start configuration on w to one containing q_accept.

Church–Turing Thesis (statement)

Every effectively calculable function is computable by a Turing machine.
