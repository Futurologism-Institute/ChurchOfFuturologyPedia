Finite Automata (NFA / DFA Equivalence)

NFA
Transition function δ : Q × (Σ ∪ {ε}) → 𝒫(Q). Acceptance by reaching any state in F after consuming the input (with possible ε-moves).
Subset Construction
Every NFA can be converted to an equivalent DFA whose states are subsets of the NFA state set.
Myhill–Nerode
A language is regular iff the number of equivalence classes under the relation x ∼_L y (∀z, xz∈L ↔ yz∈L) is finite.
