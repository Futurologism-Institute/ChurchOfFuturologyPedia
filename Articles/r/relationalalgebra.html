Relational Algebra

The relational model treats data as relations (sets of tuples). Relational algebra is a procedural query language with the following core operators:
Core Operators
σ_θ (R) — selection
π_A (R) — projection
R ∪ S — union
R − S — difference
R × S — Cartesian product
R ⋈_θ S — (theta) join
ρ (renaming)
Codd’s Theorem
Relational algebra and relational calculus have equivalent expressive power (for safe queries).
