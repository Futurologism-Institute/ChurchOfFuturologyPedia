Group Theory

A group is a set G equipped with a binary operation · satisfying:
  1. Closure: ∀a,b ∈ G, a·b ∈ G
  2. Associativity: (a·b)·c = a·(b·c)
  3. Identity: ∃e ∈ G ∀a (a·e = e·a = a)
  4. Inverses: ∀a ∃a⁻¹ (a·a⁻¹ = a⁻¹·a = e)
Abelian Group
Additionally commutative: a·b = b·a
Homomorphism
φ : G → H is a homomorphism iff φ(a·b) = φ(a)·φ(b)
Lagrange’s Theorem
If H ≤ G (finite), then |H| divides |G|.
