λ-Calculus — Symbolic Formalization

Source formalization derived from the classical untyped λ-calculus (Church, 1930s–1940).

1. Syntax (Inductive Definition)

Let Var be a countably infinite set of variables.
The set of λ-terms Λ is the smallest set such that:
  1. If x ∈ Var, then x ∈ Λ (variable).
  2. If x ∈ Var and M ∈ Λ, then (λx.M) ∈ Λ (abstraction).
  3. If M,N ∈ Λ, then (M N) ∈ Λ (application).

2. Free Variables

FV(x)          = {x}
FV(λx.M)       = FV(M) \ {x}
FV(M N)        = FV(M) ∪ FV(N)

3. Capture-Avoiding Substitution

[x := N]x      = N
[x := N]y      = y          (y ≠ x)
[x := N](λy.M) = λy.[x := N]M   (y ≠ x ∧ y ∉ FV(N))
[x := N](M P)  = ([x := N]M) ([x := N]P)

4. Reduction Rules

α-conversion
λx.M ≡_α λy.[x := y]M   (y ∉ FV(M))
β-reduction
(λx.M) N →_β [x := N]M
η-conversion (optional, extensionality)
λx.(M x) ≡_η M   (x ∉ FV(M))

5. Key Theorems (Symbolic)

  • Church–Rosser: If M →* N₁ and M →* N₂, then ∃P such that N₁ →* P and N₂ →* P (confluence up to α).
  • Turing-completeness: Untyped λ-calculus can simulate any Turing machine (and vice versa).

6. Church Numerals (Encoding)

0  ≜ λf.λx.x
1  ≜ λf.λx.f x
2  ≜ λf.λx.f (f x)
SUCC ≜ λn.λf.λx.f (n f x)
PLUS ≜ λm.λn.λf.λx.m f (n f x)
