Computability Theory

Recursive / Computable Function
A partial function f : ℕ ⇀ ℕ is partial recursive iff it is computed by some Turing machine (or equivalently by a partial recursive definition via μ-operator).
Halting Problem
The set K = {⟨e,x⟩ | φ_e(x)↓} is recursively enumerable but not recursive.
There is no algorithm that decides, for arbitrary e and x, whether the e-th Turing machine halts on x.
Rice’s Theorem
Any non-trivial semantic property of partial recursive functions is undecidable.
Recursion Theorem (Kleene)
For every total recursive f there exists e such that φ_e ≃ φ_{f(e)}.
