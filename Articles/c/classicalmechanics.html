Classical Mechanics

Newton’s Second Law
F = dp/dt  (or F = ma for constant mass)
Lagrangian Mechanics
L = T − V
Euler–Lagrange equations: d/dt (∂L/∂q̇ᵢ) − ∂L/∂qᵢ = 0
Hamiltonian Mechanics
H = Σ pᵢ q̇ᵢ − L
Hamilton’s equations: q̇ᵢ = ∂H/∂pᵢ,   ṗᵢ = −∂H/∂qᵢ
Phase Space
The state is a point in the cotangent bundle T*Q; evolution is a Hamiltonian flow.
