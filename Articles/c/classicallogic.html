Classical Logic

Propositional Logic

Language generated from atomic propositions by ¬, ∧, ∨, →, ↔.

Semantics
A valuation v assigns each atom a truth value in {0,1}. Extended recursively:
v(¬φ)=1−v(φ), v(φ∧ψ)=min(v(φ),v(ψ)), etc.
Tautology
φ is a tautology (⊨φ) iff v(φ)=1 for every valuation v.

First-Order Logic

Language with variables, constant/function/predicate symbols, quantifiers ∀, ∃.

Structure
A structure 𝔐 = (M, I) consists of a non-empty domain M and an interpretation I of the non-logical symbols.
Satisfaction
𝔐 ⊨ φ[a] defined inductively (Tarski).
Logical Consequence
Γ ⊨ φ iff every model of Γ is a model of φ.
Gödel Completeness
Γ ⊨ φ ⇔ Γ ⊢ φ (for first-order logic).
