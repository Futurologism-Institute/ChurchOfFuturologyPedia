Category Theory — Symbolic Core

Definition of a Category

A category 𝒞 consists of:
  • a collection of objects Ob(𝒞)
  • for every pair of objects A,B a set of morphisms Hom(A,B)
  • a composition operation ∘ : Hom(B,C) × Hom(A,B) → Hom(A,C)
  • identity morphisms id_A ∈ Hom(A,A)
satisfying:
Associativity
(h ∘ g) ∘ f = h ∘ (g ∘ f)
Unit laws
id_B ∘ f = f = f ∘ id_A for f : A → B

Key Concepts (Symbolic)

  • Isomorphism: f : A → B is an iso iff ∃g : B → A with g∘f = id_A and f∘g = id_B.
  • Functor F : 𝒞 → 𝒟 preserves composition and identities.
  • Natural transformation η : F ⇒ G consists of components η_A : F(A) → G(A) natural in A.
  • Adjunction: F ⊣ G with unit η and counit ε satisfying the triangle identities.
