Cryptographic Primitives

Symmetric Encryption
A scheme (Gen, Enc, Dec) is IND-CPA secure if no efficient adversary can distinguish encryptions of chosen plaintexts with non-negligible advantage.
Public-Key Encryption
Key generation produces (pk, sk). Security notions: IND-CPA, IND-CCA.
One-Way Function
f is one-way if it is easy to compute but hard to invert on average.
Trapdoor One-Way Function
Easy to invert given trapdoor information (basis of public-key crypto).
Digital Signature
(Gen, Sign, Vrfy) satisfying existential unforgeability under chosen-message attack (EUF-CMA).
