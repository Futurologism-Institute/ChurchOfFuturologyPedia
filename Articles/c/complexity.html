Computational Complexity Classes

P
Languages decidable by a deterministic Turing machine in polynomial time.
NP
Languages verifiable in polynomial time (or decided by a nondeterministic TM in polynomial time).
NP-Complete
L is NP-complete if L ∈ NP and every language in NP polynomial-time reduces to L.
P vs NP
Open question: is P = NP?
Most believe P ≠ NP.
Other classes
PSPACE, EXPTIME, BPP, BQP, etc.
