Zermelo–Fraenkel Set Theory with Choice (ZFC)

First-order theory whose only non-logical symbol is the binary membership relation ∈.

Language

Variables: x, y, z, …
Atomic formulas: x ∈ y, x = y
Connectives & quantifiers: standard first-order.

Axioms

Extensionality
∀x∀y (∀z (z∈x ↔ z∈y) → x=y)
Empty Set
∃x ∀y ¬(y∈x)   (denoted ∅)
Pairing
∀x∀y ∃z ∀w (w∈z ↔ (w=x ∨ w=y))
Union
∀x ∃y ∀z (z∈y ↔ ∃w (z∈w ∧ w∈x))
Power Set
∀x ∃y ∀z (z∈y ↔ ∀w (w∈z → w∈x))
Infinity
∃x (∅∈x ∧ ∀y (y∈x → y∪{y}∈x))
Separation (schema)
For any formula φ(z, p₁…pₙ) with free variables among those shown:
∀p₁…∀pₙ ∀x ∃y ∀z (z∈y ↔ (z∈x ∧ φ(z,p₁…pₙ)))
Replacement (schema)
If φ(x,y,p…) is functional in x, then the image of any set under the class function defined by φ is a set.
Foundation (Regularity)
∀x (x≠∅ → ∃y (y∈x ∧ y∩x=∅))
Axiom of Choice
∀x (∅∉x → ∃f (f is a choice function on x))
