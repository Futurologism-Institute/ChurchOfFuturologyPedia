Programming Language Semantics

Operational Semantics
Defines behavior via transition relations on configurations (e.g., ⟨e, σ⟩ → ⟨e′, σ′⟩).
Denotational Semantics
Maps each phrase to a mathematical object (function, domain element) compositionally.
Axiomatic Semantics
Hoare triples {P} S {Q}: if precondition P holds and S terminates, then postcondition Q holds.
Soundness & Completeness
Relative to an operational model, the axiomatic system should be sound (and ideally complete for partial correctness).
