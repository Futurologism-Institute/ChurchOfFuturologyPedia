Peano Arithmetic (PA)

Language
0, S (successor), +, ×, and the usual logical symbols.
Axioms (selected)
1. ¬(S x = 0)
2. S x = S y → x = y
3. x + 0 = x
4. x + S y = S(x + y)
5. x × 0 = 0
6. x × S y = (x × y) + x
7. Induction schema: φ(0) ∧ ∀x (φ(x) → φ(S x)) → ∀x φ(x)
Incompleteness
PA is incomplete (Gödel) and cannot prove its own consistency (second incompleteness theorem).
